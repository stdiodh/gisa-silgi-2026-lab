# 2026 정보처리기사 실기 학습 전략

## 핵심 방향

2026년 7월 19일 시험일까지 남은 기간을 기준으로 코드 출력과 SQL/DB, 보안/네트워크, 테스트/패턴을 순환합니다.

## 경향 집중 비율

- 프로그래밍 언어 활용: 40%
- SQL 응용: 15%
- 데이터베이스/자료구조: 15%
- 보안/네트워크: 15%
- 소프트웨어 공학/테스트/패턴: 15%

## D-day 운영

- D-14 ~ D-10: 10장 프로그래밍 언어 활용 집중
- D-9 ~ D-7: SQL + DB 집중
- D-6 ~ D-4: 보안 + 네트워크 + 테스트 집중
- D-3 ~ D-2: 2026 1회 경향 모의고사 반복
- D-1: 오답노트 + 암기카드
- D-Day: 체크리스트

## 코드 출력 루틴

1. 변수 초기값을 표로 적습니다.
2. 반복문 인덱스 변화를 한 줄씩 추적합니다.
3. 출력 버퍼를 별도로 기록합니다.
4. C 포인터, Java 생성자/상속, Python 슬라이싱/얕은 복사는 객체 상태를 함께 적습니다.
5. 답안 입력 후 해설의 추적 표와 비교합니다.
